## What Is Inside This Repository

This open-core edition includes 3 production-grade agent skills:

1. **`database-migration-safety`**: Prevents table locking, unindexed foreign keys, and unsafe data alterations in Postgres, Prisma, and Drizzle.
2. **`cloud-cost-guardrail`**: Flags runaway cloud resources (unnecessary NAT gateways, legacy gp2 volumes, idle forwarding rules) during IaC reviews.
3. **`human-in-the-loop-agent-guard`**: System prompt and webhook pattern to pause agents before executing destructive actions until human authorization is received.

## How to Install in Your IDE

### For Claude Code
Copy any skill folder into your project `.claude/skills/` or reference in your project `CLAUDE.md`.

### For Cursor
Copy the rule content into `.cursorrules` or `.cursor/rules/*.mdc`.

### For Antigravity / Gemini
Place inside your workspace `.gemini/skills/` directory.
